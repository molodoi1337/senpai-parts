# SENPAI.PARTS 先輩パーツ

Интернет-магазин запчастей для японских авто в стиле glassmorphism × аниме.
Демо-проект: каталог, подбор по авто/VIN, корзина и оформление заказа работают
полностью на фронтенде (мок-API с задержкой), поэтому сайт хостится как статика.

## Стек

- **React 19 + TypeScript**, сборка **Vite**
- **Tailwind CSS v4** + собственная дизайн-система (стекло, неон, стикеры, halftone) в `src/styles/index.css`
- **React Router** (17 страниц, ленивая загрузка чанков)
- **TanStack Query** — запросы к мок-API (`src/api/catalog.ts`), скелетоны, кэш
- **Zustand** (+ persist в localStorage) — корзина, гараж, избранное, сравнение, профиль/XP
- **Framer Motion** — анимации, параллакс в hero
- Вся графика (детали, машины, маскот Нэко-сэнсэй) — инлайновый SVG, без внешних картинок

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # прод-сборка в dist/
npm run preview    # посмотреть прод-сборку локально
npm run typecheck
```

## Деплой

**Vercel:** импортируй репозиторий → фреймворк Vite определится сам. `vercel.json` уже настраивает SPA-роутинг.

**Netlify:** импортируй репозиторий (настройки берутся из `netlify.toml`) или просто перетащи папку `dist/` в Netlify Drop.

Любой другой статический хостинг тоже подойдёт — главное, чтобы все пути отдавали `index.html`.

## Что внутри

| Раздел | Где |
| --- | --- |
| Главная (hero с параллаксом, бенто-категории, тайм-аттак скидок, JDM-легенды, манга-панели) | `src/pages/Home.tsx`, `src/sections/home/*` |
| Каталог: фасетные фильтры, сортировки, URL-состояние, grid/list, пагинация | `src/pages/Catalog.tsx`, `src/components/catalog/*` |
| Карточка товара: галерея с зумом, совместимость, аукционный лист, отзывы, комплекты | `src/pages/Product.tsx` |
| Корзина, промокоды, 4-шаговый чекаут с валидацией | `src/pages/Cart.tsx`, `src/pages/Checkout.tsx` |
| Гараж, подбор по авто, поиск по VIN / номеру кузова | `src/pages/Garage.tsx`, `Cars.tsx`, `CarPage.tsx`, `Vin.tsx` |
| Профиль с уровнями XP и ачивками, избранное, сравнение, журнал, FAQ, 404 | `src/pages/*` |
| Поиск ⌘K (Command Palette) | `src/components/search/CommandPalette.tsx` |
| Данные: ~50 поколений японских авто, 16 категорий, 40 брендов, ~370 товаров | `src/data/*` |

Промокоды для теста: `SENPAI10`, `ARIGATO500`, `TOFU`, `DRIFT15`.

## Подключение настоящего бэкенда

Все запросы идут через `src/api/catalog.ts` — функции возвращают ту же форму данных, что и REST API.
Достаточно заменить их тела на `fetch()` к своему серверу; компоненты менять не нужно.
